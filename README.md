# Погодный дайджест

Консольная утилита на Node.js: получает прогноз погоды по одному или нескольким
городам через открытый API Open-Meteo, выводит его в терминал и сохраняет отчёт в файл.

## Требования к окружению

- Node.js **20+**
- Доступ в интернет 

## Установка

```bash
git clone https://github.com/e1shiy/caselab-weather.git
cd caselab-weather
npm i
cp .env.example .env
```

## Переменные окружения

- `GEOCODING_API_URL` - Базовый URL API геокодинга - `https://geocoding-api.open-meteo.com/v1/search`
- `FORECAST_API_URL` - Базовый URL API прогноза - `https://api.open-meteo.com/v1/forecast`
- `REQUEST_TIMEOUT_MS` - Таймаут одного HTTP-запроса, мс - `5000`
- `REPORTS_PATH` - Каталог для сохранения отчётов - `./reports`

## Запуск

```bash
node src/index.js --city "Нижний Новгород" --days 3
node src/index.js --city "Москва, Париж, Токио" --days 5
node src/index.js --city "Москва" --no-cache
```

| Параметр      | Обязательный | Описание                                                        |
|----------------|:------------:|-------------------------------------------------------------------|
| `--city`       | да           | Город или список городов через запятую                            |
| `--days`       | нет          | Целое число дней прогноза, 1–7 (по умолчанию 3)                   |
| `--no-cache`   | нет          | Игнорировать сохранённый на сегодня отчёт и выполнить запрос заново |

## Пример вывода

```
Москва, Россия (55.75, 37.62)

  2026-09-15   +18.4°C / +9.1°C   осадки: 0.0 мм
  2026-09-16   +17.9°C / +8.7°C   осадки: 1.2 мм
  2026-09-17   +16.2°C / +7.5°C   осадки: 3.4 мм

Не удалось получить прогноз:
  - Чокопай: Город "Чокопай" не найден
```

## Обрабатываемые ошибки и коды завершения

- отсутствующий/некорректный `--city` или `--days` — сообщение и справка, выход **до** сетевых запросов;
- город не найден;
- ответ `4xx` — ошибка запроса;
- ответ `5xx` — сервис временно недоступен;
- сеть недоступна;
- превышен таймаут;
- некорректный JSON в ответе API.

Во всех случаях пользователю показывается соответствующее сообщение.

**Код завершения процесса:**
- `0` — хотя бы один город обработан успешно;
- `1` — не указаны/некорректны аргументы, либо не удалось получить прогноз ни по одному из запрошенных городов.

## Структура проекта

```
src/
  index.js          — разбор аргументов, валидация, запуск, завершение
  api/
    geocoding.js     — клиент геокодинга (fetch, таймаут, разбор ошибок)
    forecast.js      — клиент прогноза погоды (fetch, таймаут, разбор ошибок)
  services/
    weather.js        — бизнес-логика: параллельная обработка городов, кэш
  storage/
    reportStorage.js  — чтение/запись отчётов
  format/
    terminal.js        — форматирование вывода в консоль
docs/postman/
  weather-digest.postman_collection.json — коллекция Postman с примерами ответов
reports/            — сохранённые отчёты
```
